# CleanSheet Pro

CleanSheet Pro is a powerful, browser-based tool for cleaning, transforming, and visualizing spreadsheet data. It's built entirely in a single HTML file, using React and SheetJS to provide a seamless, client-side data manipulation experience.

## Features

- **File Parsing**: Supports CSV and Excel (.xlsx, .xls) files.
- **Data Cleaning**: Apply a variety of rules to filter, clean, and transform your data.
- **Data Visualization**: Get a quick overview of your data with simple column statistics.
- **Data Reconciliation**: Compare two datasets to find matches and differences.
- **Data Export**: Export your cleaned data to CSV, Excel, JSON, or SQL formats.
- **Saved Recipes**: Save and reuse your data cleaning rules.

## Setup

There is no setup required. Simply open the `Index.html` file in your web browser to start using the application.

## Usage

1. **Load Data**: Drag and drop a spreadsheet file onto the upload area, or click to select a file.
2. **Clean Data**:
   - **Filter Logic**: Add rules in the sidebar to filter rows based on conditions.
   - **Transformations**: Use the toolbar to perform actions like trimming whitespace, finding and replacing text, changing case, removing duplicates, and splitting columns.
3. **Visualize Data**: Click the "Visualize" tab to see a breakdown of values for each column.
4. **Reconcile Data**: Click the "Reconcile" tab to compare two different spreadsheet files.
5. **Export Data**: Once your data is clean, use the export buttons in the header to download the results.
